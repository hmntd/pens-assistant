> **Мова документації:** 🇺🇦 **Українська** | [🇬🇧 **English**](../README.md)

**PensAssistant** — це мікросервісна платформа для автоматизованого розрахунку та аудіту пенсійних виплат, розроблена відповідно до Закону України № 1058-IV *"Про загальнообов'язкове державне пенсійне страхування"*.

Система поєднує в собі веб-оркестратор, високоточний OCR-сервіс для розпізнавання трудових книжок та довідок про доходи за координатами й шаблонами, автоматичні скрапери для збору даних з порталу Пенсійного фонду України (ПФУ) та високопродуктивний обчислювальний движок на C++ із алгоритмом ковзного вікна для пошуку оптимального заробітку за будь-які 60 місяців поспіль до 2000 року.

```

                                 │   Vue 3 Frontend (Atomic UI)  │
                                 └──────────────┬────────────────┘

┌──────────────────────────┐    gRPC    ┌───────────────────────────────┐    gRPC    ┌──────────────────────────┐

└──────────────────────────┘            └──────────────┬────────────────┘            └──────────────────────────┘
                                                       │ Cron / Скрапери
```

### 1. Веб-оркестратор та CRM (`/crm`)
* **Фреймворк:** Laravel 13, Inertia.js v3, PHP 8.5
* **Фронтенд UI:** Vue 3 (Composition API), архітектура Atomic Design, Tailwind CSS, Lucide Icons, push-сповіщення `vue-sonner`.
* **Real-time WebSockets:** Laravel Reverb & Laravel Echo (двосторонні приватні WebSocket-канали для оновлення UI в реальному часі без перезавантаження сторінки).
* **Аутентифікація:** Laravel Fortify & Socialite (OAuth2: Google, LinkedIn, GitHub, Microsoft Azure), 2FA, Passkeys (WebAuthn).
* **Черги та асинхронні задачі:** Redis, Laravel Horizon.
* **Генерація PDF-звітів:** Dompdf (`barryvdh/laravel-dompdf`), підтримка двомовних звітів (UK/EN).

### 2. Високопродуктивний обчислювальний движок C++ (`/calc`)
* **Ядро:** C++20, gRPC, Protocol Buffers (`/protos`).
* **Паттерни проектування:** Стратегія (`IBenefitStrategy`, `BenefitRulesEngine`), алгоритм ковзного вікна (Sliding Window).
* **Призначення:** Розрахунок 5-етапного пенсійного математичного пайплайну з мікросекундною затримкою.

### 3. OCR Сервіс Розпізнавання Документів (`/ocr`)
* **Ядро:** Python 3.12, gRPC.
* **Механізм:** Прив'язка до просторових координат та графічних шаблонів для точного витягування стажу й довідок про зарплату без втрати даних.

### 4. Стек моніторингу контейнерів та інфраструктури
* **Збір метрик ресурсів:** cAdvisor (`v0.49.1`) для збору телеметрії CPU, RAM, мережевого трафіку та Disk I/O безпосередньо з cgroups контейнерів Linux.
* **Сховище часових рядів:** Prometheus (`v2.53.0`), що зчитує метрики cAdvisor кожні 5 секунд.
* **Візуалізація метрик:** Grafana (`v11.1.0`) з автоматичною ініціалізацією дашбордів ресурсного навантаження Docker-контейнерів (`/grafana/`).
* **Захист шлюзу:** Доступ захищено на рівні Nginx субреквестом (`auth_request /admin/auth-check`) через контролер `AdminAuthCheckController` в Laravel CRM (`403 Forbidden` для неавторизованих користувачів).

### 5. База даних та основна інфраструктура
* **СУБД:** PostgreSQL 16.
* **Кеш та брокер черг:** Redis Alpine.
* **Контейнеризація:** Docker & Docker Compose (`docker-compose.yml`).
* **CI/CD та деплой:** GitHub Actions (зі сканером безпеки Trivy), хмарне розгортання на AWS із підтримкою безперервного деплою без зупинки сервісу (Deployer / Zero-Downtime Deployment).

## ✨ Основні функції та механіка роботи

### 🧮 1. 5-Етапний обчислювальний пайплайн C++
C++ движок розраховує пенсію за базовою законодавчою формулою:
$$\text{Базова пенсія } (P_{\text{базова}}) = Z_p \times K_z \times K_s$$

* **$Z_p$ (Середня зарплата в Україні):** Показник середньої заробітної плати в Україні за 3 роки, що передують року звернення.
* **$K_z$ (Коефіцієнт заробітку):** Зважене співвідношення місячного доходу заявника до середньої зарплати по країні.
* **$K_s$ (Коефіцієнт страхового стажу):** Обчислюється за формулою $\frac{\text{Місяці стажу}}{1200}$.

### 🔍 2. Пошук кращого 60-місячного періоду до 2000 року (Ковзне вікно)
Відповідно до законодавства України, громадяни мають право врахувати будь-які 60 місяців страхового стажу поспіль до 1 липня 2000 року для підвищення коефіцієнта $K_z$.
* Движок C++ застосовує **алгоритм ковзного вікна (Sliding Window)** за всіма зафіксованими місяцями заробітку до 2000 року.
* Система автоматично виявляє єдиний 5-річний continuous-період, який дає найвищий коефіцієнт $K_z$.

### ⏱️ 3. Доплати за понаднормовий страховий стаж
* Автоматично визначає понаднормові роки стажу понад встановлену норму (35 років для чоловіків, 30 років для жінок).
* Нараховує $+1\%$ від базової пенсії (або прожиткового мінімуму) за кожен повний рік понаднормового стажу.

### 🎖️ 4. Гнучка система пільг та доплат (Паттерн Стратегія)
Доплати динамічно розраховуються від прожиткових мінімумів, збережених у базі даних (`subsistence_minimums`):
* **Учасник бойових дій (УБД):** $+25\%$ прожиткового мінімуму для осіб, які втратили працездатність (ст. 12 ЗУ *"Про статус ветеранів війни"*).
* **Почесний донор України:** $+10\%$ загального прожиткового мінімуму (ст. 21 ЗУ *"Про донорство крові"*).
* **Чорнобилець-ліквідатор:** $+30\%$ прожиткового мінімуму для осіб, які втратили працездатність (ст. 13 ЗУ *"Про статус і соціальний захист громадян, які постраждали внаслідок Чорнобильської катастрофи"*).
* **Догляд за дитиною з інвалідністю:** $+10\%$ прожиткового мінімуму для осіб, які втратили працездатність.

### 🤖 5. Точне OCR розпізнавання за шаблонами та координатами
* Використовує задані системи координат для точного витягування даних з таблиць довідок.
* Обробка відбувається асинхронно через черги під управлінням **Laravel Horizon**.

### 🔄 6. Автоматичні Cron-задачі та скрапери сайтів ПФУ
* **Скрапер середньої зарплати:** Cron-задача, яка автоматично витягує оновлені показники середньої зарплати з порталу ПФУ.
* **Скрапер прожиткових мінімумів:** Cron-задача, що оновлює розміри державних прожиткових мінімумів.
* **Скрапер новин ПФУ:** Cron-задача для наповнення стрічки актуальних новин.

### 📊 7. Панель адміністратора та моніторинг системних помилок
* **Аналітика та графіки:** Динамічні діаграми кількості розрахунків, демографічного розподілу користувачів, статистики документів.
* **Управління користувачами та документами:** Повноцінна модель ролей (RBAC), м'яке видалення, блокування акаунтів.
* **Монітор помилок та журнал виправлень:** Фіксація 5xx помилок та клієнтських збоїв із кнопками пакетного вирішення.

### 📄 8. Генерація та завантаження PDF-звітів
* Пряме завантаження згенерованих PDF-документів на пристрій користувача.
* Підтримка окремих мовних шаблонів (`pension_calculation_report_uk.blade.php` та `pension_calculation_report_en.blade.php`), що відповідають мові інтерфейсу.

### ⚡ 9. Real-Time WebSockets на єдиній сторінці (Laravel Reverb & Echo)
* **Призначення:** Повністю усуває потребу перезавантажувати сторінку чи опитувати сервер (polling) під час асинхронних фонових задач (OCR розпізнавання довідок та обчислення пенсії в C++ движку).
* **Реалізація та механіка роботи:**
  * Коли користувач натискає "Запустити розрахунок пенсії", запит миттєво з'являється в інтерфейсі зі статусом "В черзі", а математична задача відправляється у чергу Redis під управлінням **Laravel Horizon** та C++ движка.
  * Після завершення розрахунку бекенд CRM транслює broadcast-подію (`PensionCalculationUpdated` / `NotificationCreated`) через **Laravel Reverb** (працює в контейнері `pens_crm_reverb:8080`).
  * Фронтенд на Vue 3 прослуховує події через **Laravel Echo** у приватному каналі користувача (`private-user.{id}`), автоматично змінюючи статус запису з "В черзі" на "Розраховано", підтягуючи результати обчислення та спливаюче push-сповіщення у реальному часі **без перемикання секцій та без оновлення сторінки**.

### 📈 10. Моніторинг ресурсів контейнерів та інфраструктури (Prometheus + cAdvisor + Grafana)
* **Призначення:** Забезпечує повний моніторинг у реальному часі споживання CPU, RAM, мережевого трафіку та Disk I/O за всіма 12 контейнерами мікросервісів (`pens_ocr`, `pens_calc`, `pens_crm`, `pens_redis`, `pens_crm_db` тощо). Запобігає непоміченим падінням контейнерів при пікових навантаженнях (наприклад, під час масового OCR розпізнавання сканів) та дозволяє демонструвати стабільність системи на захисті дипломного проєкту.
* **Реалізація та механіка роботи:**
  * **cAdvisor (`gcr.io/cadvisor/cadvisor:v0.49.1`):** Збирає нативні метрики Linux cgroups для кожного контейнера (`-url_base_prefix=/cadvisor`).
  * **Prometheus (`prom/prometheus:v2.53.0`):** Сховище часових рядів, яке опитує cAdvisor кожні 5 секунд.
  * **Grafana (`grafana/grafana:11.1.0`):** Візуальний движок дашбордів з авто-ініціалізацією графіків навантаження Docker-контейнерів (`/grafana/`).
  * **Захист шлюзу:** Доступ до `/grafana/`, `/prometheus/` та `/cadvisor/` суворо обмежено на рівні Nginx субреквестом (`auth_request /admin/auth-check`) через `AdminAuthCheckController`. Авторизовані адміністратори CRM отримують безшовний доступ без повторного введення пароля (anonymous SSO), а звичайні користувачі або гості отримують відповідь `403 Forbidden`.

## 🚀 Встановлення та локальний запуск

### Передумови
* Docker Engine `^24.0` та Docker Compose `^2.20`
* Git

### Покрокова інструкція

1. **Клонувати репозиторій:**
   ```bash
   git clone https://github.com/hmntd/pens-assistant.git
   cd pens-assistant
   ```

2. **Налаштувати файл оточення:**
   ```bash
   cp crm/.env.example crm/.env
   ```

3. **Запустити Docker-контейнери:**
   ```bash
   docker compose up -d --build
   ```

4. **Встановити залежності та виконати міграції:**
   ```bash
   docker compose exec crm composer install
   docker compose exec crm php artisan key:generate
   docker compose exec crm php artisan migrate --seed
   ```

5. **Зібрати фронтенд бандли:**
   ```bash
   docker compose exec crm npm install
   docker compose exec crm npm run build
   ```

6. **Доступ до платформи:**
   * **Веб-додаток:** [http://localhost:8000](http://localhost:8000)
   * **Моніторинг черг Horizon (Admin):** [http://localhost:8000/horizon](http://localhost:8000/horizon)
